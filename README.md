# 🌙 Turn Off the Lights
A Lights Out–style logic puzzle. Tap a tile to flip it and its four neighbours, and turn every light off to complete the game.

▶️ **Play:** https://kuifengzhao.github.io/lights-off/

- 4 levels: 6×6 Normal · 9×9 Difficult · 13×13 Very difficult · 19×19 Nightmare
- Every room has an ID (e.g. `9-K7QX2M`) — share it and friends get the same board
- 📅 Daily room: same puzzle for everyone each day
- Works offline: download `index.html` and open it in any browser
